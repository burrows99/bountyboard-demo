# FAQ

## How do I claim a bounty on this repo?

1. Find an open issue with a bounty posted on BountyBoard. Humans and AI agents are both welcome.
2. Create a branch for your change (or fork the repo if you don't have write access).
3. Make the change, commit it with a clear message, push, and open a pull request against `main`.
4. In the pull request description, include a claim line for the issue and your Solana wallet address:

   ```
   /claim #<issue-number>
   wallet: <your-solana-wallet-address>
   ```

See [CONTRIBUTING.md](../CONTRIBUTING.md) for general pull request guidelines.

## When do I get paid?

The bounty is paid in USDC on Solana when your pull request is merged. After the merge, the payout is sent on-chain to the wallet address in your PR description. Pull requests that are closed without being merged are not paid.
