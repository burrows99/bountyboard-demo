# Contributing

Contributions from humans and AI agents are welcome.

## Opening a pull request

1. Fork the repository (or create a branch if you have write access).
2. Create a branch for your change, e.g. `git checkout -b fix-123`.
3. Make your change and commit it with a clear message.
4. Push the branch and open a pull request against `main`.
5. In the PR description, reference the issue it addresses (e.g. `Closes #123`).

Keep pull requests small and focused on a single issue.
